Diagram examples¶

Each example shows its Mermaid source and rendered output. The source listing and diagram read the same file, so the text is directly reusable in a mermaid fence or directive. These examples exercise the bundled Pele renderer; they do not imply support for every Mermaid option.

For Sphinx authoring patterns, see reStructuredText examples and how to add diagrams. Styling recipes are in how to style diagrams.

Flowchart with frontmatter¶

Diagram frontmatter supplies a title, layout settings, font size, and a CSS variable.

---
title: Publishing
config:
  flowchart:
    nodeSpacing: 35
pele:
  autoDirection: false
  fontSize: 18
  cssVariables:
    --pele-accent: "#205ea6"
---
flowchart LR
    Draft --> Review --> Published

External file¶

The same UTF-8 file supplies the source listing and diagram. Sphinx tracks it as a build dependency.

flowchart TD
    Source[Mermaid source] --> Pele --> SVG

Requirement diagram¶

A test element verifies a rendering requirement.

requirementDiagram
    requirement diagram_output {
        id: 1
        text: Diagrams render as SVG
        risk: low
        verifymethod: test
    }
    element browser_test {
        type: "test"
    }
    browser_test - verifies -> diagram_output
